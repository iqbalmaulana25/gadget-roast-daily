Entry for [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) on make.fun.

`main.ts` (Node 22, no dependencies) writes one roast — at most 200
characters — of the gadget used every day, to `/output/entry.txt`. The
target: a phone battery that coasts for nine hours, then dies in the time
it takes to find the charger.

Run it with:

```sh
node main.ts
```
